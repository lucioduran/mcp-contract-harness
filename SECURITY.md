# Security

This project is a local read-only reference server, not a security-certified
implementation. It exposes fixed fictional notes and does not interpret resource
URIs as filesystem paths. SDK HTTP and authentication features are not used.

Report a suspected vulnerability privately through GitHub's security reporting
feature when available, or contact email@lucioduran.com. Do not publish secrets
or private transcripts in an issue. Include a minimal synthetic reproduction.
No response-time guarantee or independent security review is claimed.
